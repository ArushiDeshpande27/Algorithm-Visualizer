<h1>Algorithm Visualizer</h1>

An interactive **Sorting Algorithm Visualizer** built using **HTML, CSS, and JavaScript** that helps users understand how sorting algorithms work through animated visualizations.

The project allows users to generate random arrays and observe how different algorithms sort the data step-by-step. Visualizing algorithms helps learners understand their behavior and performance more effectively than only reading theory. ([Scribd][2])

<h1>Features</h1>

* Generate a **random array of numbers**
* Select different **sorting algorithms**
* **Animated visualization** of sorting process
* Displays **algorithm information and time complexity**
* Color highlighting to show comparisons during sorting
* Supports multiple sorting algorithms

<h1>Algorithms Implemented</h1>


The visualizer currently supports the following algorithms:

<h3>Bubble Sort</h3>

* Time Complexity: **O(n²)**
* Space Complexity: **O(1)**
* Works by repeatedly swapping adjacent elements.

<h3>Selection Sort</h3>

* Time Complexity: **O(n²)**
* Space Complexity: **O(1)**
* Repeatedly selects the smallest element and places it in the correct position.

<h3>Insertion Sort</h3>

* Time Complexity: **O(n²)** (Worst case)
* Best Case: **O(n)**
* Builds the sorted array one element at a time.

<h2>How to Use</h2>

1. Click **Generate Numbers** to create a random array.
2. Select a sorting algorithm from the dropdown.
3. Click **Start Sorting** to visualize the algorithm.
4. Watch how the bars move and rearrange as the algorithm sorts the array.

Algorithm visualization makes it easier to see how data changes step by step during execution. ([Scribd][2])
